<img width="1899" height="794" alt="image" src="https://github.com/user-attachments/assets/42690226-ac08-4412-b28d-3398ae4a59dc" /># 🚀 SmartHire AI – ATS Resume Analyzer

SmartHire AI is an AI-powered ATS Resume Analyzer that compares resumes with job descriptions and generates ATS scores, matched skills, AI recommendations, visual analytics, and downloadable PDF reports.


## ✨ Features

- 📄 Resume Upload
- 🎯 ATS Score Analysis
- 🧠 Skill Matching
- 🤖 AI Recommendations
- 💪 Resume Strength Detection
- 📊 Dynamic Pie Charts
- 📈 Animated Progress Bar
- 📥 PDF Report Download
- 🌙 Dark/Light Theme Toggle
- 📱 Responsive UI
- ☁️ Live Deployment on Render


## 🛠️ Tech Stack

### Frontend
- HTML

- JavaScript
- Chart.js

### Backend
- Python
- Flask

### AI / NLP
- spaCy

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Aniket-03-AI/SmartHire-AI.git
```

### 2️⃣ Open Project Folder

```bash
cd SmartHire-AI
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run Application

```bash
python app.py
```

### 5️⃣ Open in Browser

```bash
http://127.0.0.1:5000
```

## 🧠 How It Works

1. Upload Resume PDF  
2. Paste Job Description  
3. System Extracts Resume Text  
4. NLP Matching is Performed  
5. ATS Score is Generated  
6. AI Recommendations are Displayed  
7. PDF Report can be Downloaded
